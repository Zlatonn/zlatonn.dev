# Zlatonn's Space

A single-page personal portfolio that shows who Zlatonn is, the projects they built, and how to contact them.

## Language

**Project**:
A piece of work shown in the Projects section, with a title, a period, a short description and the Techs it was built with.
_Avoid_: Work, item, portfolio entry

**Tech**:
One named technology that a Project lists as used to build it, written exactly as that Project lists it (for example "React", "Express").
_Avoid_: Tag, skill, stack item

**Tech showcase**:
The "MY TECH STACK" list of technologies Zlatonn knows. It is a separate list from the Techs on Projects, and its names do not have to match them.
_Avoid_: Tech stack (ambiguous), skills list
